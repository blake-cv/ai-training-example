05 / Open the door

Files on your laptop.
A link for everyone.

Hosting makes your website files available to people on the internet.

GitHub stores the project. GitHub Pages serves the website. For this kind of site, they work together without a separate hosting account.

Real publishing takes time—sometimes up to 10 minutes. This example moves forward when you click.

    Describe one useful idea.

    Use the prompt. Ask your AI tool for the three files.

    Preview it. Make it yours.

    Read the content, test the controls, and request changes.

    Create a public GitHub repository.

    Give it a name. Add a README so the repo starts with a main branch.

  4. 04
    Upload and commit your files.

    Add file → Upload files. Put index.html, styles.css, and script.js at the top level.

  5. 05
    Turn on Pages. Share the link.

    Settings → Pages → Deploy from a branch → main → /(root) → Save. Wait for deployment, then visit your site.
